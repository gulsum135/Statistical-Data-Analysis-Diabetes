# Statistical Data Analysis: Diabetes Dataset

Bu proje, diyabet veri seti (`diabetes.csv`) üzerinde temel istatistiksel analizler ve veri işleme tekniklerini uygulamak amacıyla geliştirilmiştir. Proje, verilerin anlamlandırılması, merkezi eğilim ölçülerinin hesaplanması ve sonuçların raporlanması süreçlerini kapsar.

## 📊 Analiz İçeriği
- **Veri Ön İşleme:** Eksik veya hatalı verilerin temizlenmesi ve analize hazır hale getirilmesi.
- **Betimsel İstatistik:** Ortalama, medyan, standart sapma gibi temel istatistiksel değerlerin hesaplanması.
- **Olasılık ve Dağılım Analizi:** Veri seti içerisindeki değişkenlerin dağılım özelliklerinin incelenmesi.
- **Sonuç Raporlama:** Analiz çıktılarının sistematik bir şekilde `sonuc.txt` dosyasına aktarılması.

## 📂 Dosya Yapısı
- `diabetes.csv`: Analiz edilen diyabet hasta verileri.
- `diabetes_data_analysis.py`: Python ile geliştirilen analiz ve hesaplama betiği.
- `sonuc.txt`: Kodun çalıştırılması sonucunda üretilen istatistiksel rapor.

Analizi çalıştırmak için Python ortamında aşağıdaki komutu kullanabilirsiniz:
